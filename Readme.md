## Sobre o projeto

O DellCreators é um projeto desenvolvido em equipe utilizando HTML e CSS. O projeto possui uma página principal com jogos fictícios, histórias e imagens, além das páginas Sobre e Contato.

## Divisão do trabalho

Kauan Damacena Dos Santos ficou responsável pelo `index.html` e pela criação do conteúdo dos jogos.

Eduardo ficou responsável pelo `style.css` e pela estilização de todas as páginas.

## Objetivo

O objetivo do projeto foi desenvolver uma página web em equipe e colocar em prática os conhecimentos de HTML, CSS, Git e GitHub.
